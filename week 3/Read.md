# Task 1: Revenue per Transaction

## Objective

Calculate the monetary value generated by each transaction line item.

## Methodology

Revenue is computed by multiplying the quantity of items purchased by their corresponding unit price.

### Formula

Revenue = Quantity × UnitPrice

### Implementation

A new column named `Revenue` is created:

```python
df['Revenue'] = df['Quantity'] * df['UnitPrice']
```

### Output

The dataset is extended with an additional column:

| InvoiceNo | Quantity | UnitPrice | Revenue |
| --------- | -------: | --------: | ------: |
| 536365    |        6 |      2.55 |   15.30 |
| 536365    |        6 |      3.39 |   20.34 |

### Significance

The Revenue metric represents the financial contribution of each transaction and serves as the foundation for subsequent metrics such as Average Order Value (AOV) and Customer Lifetime Value (CLTV).

# Task 2: Average Order Value (AOV) per Cohort

## Objective

Determine the average amount spent per order for each customer cohort.

## Methodology

Since a single invoice may contain multiple products, the revenue generated by all products belonging to the same invoice is first aggregated to obtain the total order value.

### Step 1: Calculate Order Value

```python
order_value = (
    df.groupby(['InvoiceNo', 'CohortMonth'])['Revenue']
      .sum()
      .reset_index()
)
```

### Step 2: Calculate Average Order Value

```python
aov = (
    order_value.groupby('CohortMonth')['Revenue']
               .mean()
               .reset_index()
)

aov.columns = ['CohortMonth', 'AOV']
```

### Formula

AOV = Total Revenue / Number of Orders

### Significance

Average Order Value measures customer spending behaviour across different cohorts and helps identify customer groups that generate higher revenue per purchase.

# Task 3: Cohort Segmentation

## Objective

Analyse revenue metrics across different customer segments.

## Limitation

The dataset does not contain explicit acquisition information such as:

* Marketing Campaign
* Referral Source
* Organic Search
* Social Media Channel

Therefore, customer acquisition channel segmentation could not be performed directly.

## Alternative Approach

Customer geography (`Country`) was used as a proxy segmentation variable to analyse revenue contribution across different regions.

### Revenue by Cohort and Country

```python
country_revenue = (
    df.groupby(['CohortMonth', 'Country'])['Revenue']
      .sum()
      .reset_index()
)
```

### Average Order Value by Cohort and Country

```python
order_value_country = (
    df.groupby(['InvoiceNo', 'CohortMonth', 'Country'])['Revenue']
      .sum()
      .reset_index()
)

country_aov = (
    order_value_country
      .groupby(['CohortMonth', 'Country'])['Revenue']
      .mean()
      .reset_index()
)

country_aov.columns = ['CohortMonth', 'Country', 'AOV']
```

### Significance

Geographical segmentation helps identify countries that contribute higher revenue and exhibit greater average spending patterns, enabling region-wise business insights.
