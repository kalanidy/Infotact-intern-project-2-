# Week 3 - Day 1: Calculate Total Revenue per Customer

## Date

**24 June**

## Task

Calculate the total revenue generated by each customer from the cleaned online retail dataset.

## Objective

The objective of this task is to compute the total revenue contributed by each customer. This serves as the foundation for calculating **Average Order Value (AOV)** in the following tasks.

## Dataset

**File:** `cleaned_retail_data_updatedw3.csv`

## Columns Used

* `CustomerID`
* `Quantity`
* `UnitPrice`

## Methodology

### Step 1: Load the Dataset

Import the cleaned retail dataset into a Pandas DataFrame.

### Step 2: Calculate Transaction Revenue

Create a new column named **TotalRevenue** using the following formula:

```
TotalRevenue = Quantity × UnitPrice
```

Each row now represents the revenue generated from a single transaction.

### Step 3: Calculate Total Revenue per Customer

Group the dataset by **CustomerID** and calculate the sum of **TotalRevenue** for each customer.

## Output

The output is a customer-level revenue table containing:

| CustomerID | TotalRevenue |
| ---------- | -----------: |
| 12346      |     77183.60 |
| 12347      |      4310.00 |
| 12348      |      1797.24 |

## Technologies Used

* Python
* Pandas
* Jupyter Notebook

## Outcome

The calculated customer revenue will be used in the next task to determine the **Average Order Value (AOV)** by combining total revenue with the total number of unique orders.
